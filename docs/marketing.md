# 上线注意事项

1. **学生端价格必须一次性展示清楚**
   不要先写低价，后面再加"服装费、平台费、预约费"。英国现在对 drip pricing 很敏感。

2. **平台不要收学生钱**
   不要让学生把钱打给平台，也不要平台再转给摄影师。

3. **不要写"平台担保退款"**
   可以写"平台协助沟通"，不要写"平台保证退款"。

4. **付款截图只做核对，不做支付处理**
   文案里一定要写清楚：截图用于摄影师核对到账和订单记录。

5. **摄影师身份要清楚**
   学生要能看到摄影师名称、套餐、价格、服务内容、交付时间、取消规则。

6. **所有自动邮件都保留记录**
   邮件是 durable medium，对消费者合同确认很有帮助。

7. **微信收款码页面不要做成平台收银台**
   页面标题建议写：
   "请直接向摄影师付款 / Pay the photographer directly"
   不要写：
   "平台支付 / Checkout / Pay Platform"。

8. **营销别过度攻击具体商家**
   "拒绝被传统套餐劝退"比"某某公司割韭菜"更安全，也更适合长期投放。
